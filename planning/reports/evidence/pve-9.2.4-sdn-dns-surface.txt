my sub powerdns_api_request {
    my ($config, $method, $path, $params) = @_;

    return PVE::Network::SDN::api_request(
        $method,
        "$config->{url}${path}",
        ['Content-Type' => 'application/json; charset=UTF-8', 'X-API-Key' => $config->{key}],
        $params,
        $config->{fingerprint},
    );
}

  => the plugin's `url` is a full API base and paths are appended verbatim.
     on_update_hook GETs it bare; get_zone_content GETs "$url/zones/$zone";
     verify_zone GETs "$url/zones/$zone?rrsets=false"; every write is a
     single PATCH "$url/zones/$zone" with {"rrsets": [...]}. There is no
     per-record route: an rrset is replaced whole (changetype REPLACE), or
     removed whole (changetype DELETE with an empty records list).
