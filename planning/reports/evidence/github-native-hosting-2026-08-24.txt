## Consequences for T-3709
 1. GitHub-native static hosting is ALREADY WORKING: Pages builds main root on every push.
    A signed index committed to the repo is published by infrastructure that runs today.
 2. Sigstore keyless signing needs an OIDC token from an Actions run. No non-Pages workflow
    has run since 2026-08-13. Until that is resolved, a real keyless signature CANNOT be
    produced. This is the binding constraint on the signing-custody decision.
 3. The vnprox.com zone IS under the owner's control and answers publicly — so the
    'no public DNS' gap is a record change, not the VPS reverse-proxy leg phase-33 assumed.
