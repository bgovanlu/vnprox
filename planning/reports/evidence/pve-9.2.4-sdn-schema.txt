  Add a fabric

  --digest   <string>
	     Prevent changes if current configuration file has a different
	     digest. This can be used to prevent concurrent modifications.

  --protocol <bgp | openfabric | ospf | wireguard>

 Conditional options:

  --redistribute <array>

 [protocol=openfabric]

  --csnp_interval <number> (1 - 600)
	     The csnp_interval property for Openfabric

  --hello_interval <number> (1 - 600)
	     The hello_interval property for Openfabric

  --route_filter <string>
	     A prefix list that should be used for filtering routes that
	     are to be installed into the kernel routing table

 [protocol=ospf]

  --area     <string>
	     OSPF area. Either a IPv4 address or a 32-bit number. Gets
	     validated in rust.

  --redistribute <array>
	     no description available

  --route_filter <string>
	     A prefix list that should be used for filtering routes that
	     are to be installed into the kernel routing table

 [protocol=wireguard]

  --persistent_keepalive <number> (0 - 65535)
	     A seconds interval, between 1 and 65535 inclusive, of how
	     often to send an authenticated empty packet to the peer for
	     the purpose of keeping a stateful firewall or NAT mapping
	     valid persistently. For example, if the interface very rarely
	     sends traffic, but it might at anytime receive traffic from
	     another node, and it is behind NAT, the interface might
	     benefit from having a persistent keepalive interval of 25
	     seconds. If unset or set to 0, it is turned off


### usage /cluster/sdn/zones (type enum)
USAGE: pvesh get /cluster/sdn/zones  [OPTIONS]

  SDN zones index.

  --pending  <boolean>
	     Display pending config.

  --running  <boolean>
	     Display running config.

  --type     <evpn | faucet | qinq | simple | vlan | vxlan>
	     Only list SDN zones of specific type

USAGE: pvesh create /cluster/sdn/zones --type <string> --zone <string> [OPTIONS]

  Create a new sdn zone object.

  --advertise-subnets <boolean>
	     Advertise IP prefixes (Type-5 routes) instead of MAC/IP pairs
	     (Type-2 routes).

  --bridge   <string>
	     The bridge for which VLANs should be managed.

  --bridge-disable-mac-learning <boolean>
	     Disable auto mac learning.

  --controller <string>
	     Controller for this zone.

  --dhcp     <dnsmasq>
	     Type of the DHCP backend for this zone

  --disable-arp-nd-suppression <boolean>
	     Suppress IPv4 ARP && IPv6 Neighbour Discovery messages.

  --dns      <string>
	     dns api server

  --dnszone  <string>
	     dns domain zone  ex: mydomain.com

  --dp-id    <integer>
	     Faucet dataplane id

  --exitnodes <string>
	     List of cluster node names.

  --exitnodes-local-routing <boolean>
	     Allow exitnodes to connect to EVPN guests.

  --exitnodes-primary <string>
	     Force traffic through this exitnode first.

  --fabric   <string>
	     SDN fabric to use as underlay for this VXLAN zone.

  --ipam     <string>
	     use a specific ipam

  --lock-token <string>
	     the token for unlocking the global SDN configuration

  --mac      <string>
	     Anycast logical router mac address.

  --mtu      <integer>
	     MTU of the zone, will be used for the created VNet bridges.

  --nodes    <string>
	     List of cluster node names.

  --peers    <string>
	     Comma-separated list of peers, that are part of the VXLAN
	     zone. Usually the IPs of the nodes.

  --reversedns <string>
	     reverse dns api server

  --rt-import <string>
	     List of Route Targets that should be imported into the VRF of
	     the zone.

  --secondary-controllers <array>
	     Additional controllers.

  --tag      <integer> (0 - N)
	     Service-VLAN Tag (outer VLAN)

  --type     <evpn | faucet | qinq | simple | vlan | vxlan>
	     Plugin type.

  --vlan-protocol <802.1ad | 802.1q>   (default=802.1q)
	     Which VLAN protocol should be used for the creation of the
	     QinQ zone.

  --vrf-vxlan <integer> (1 - 16777215)
	     VNI for the zone VRF.

  --vxlan-port <integer> (1 - 65536)   (default=4789)
	     UDP port that should be used for the VXLAN tunnel (default
	     4789).

  --zone     [a-zA-Z][a-zA-Z0-9]*[a-zA-Z0-9]
	     The SDN zone object identifier.


### usage /cluster/sdn/controllers (type enum)
USAGE: pvesh get /cluster/sdn/controllers  [OPTIONS]

  SDN controllers index.

  --pending  <boolean>
	     Display pending config.

  --running  <boolean>
	     Display running config.

  --type     <bgp | evpn | faucet | isis>
	     Only list sdn controllers of specific type

USAGE: pvesh create /cluster/sdn/controllers --controller <string> --type <string> [OPTIONS]

  Create a new sdn controller object.

  --asn      <integer> (0 - 4294967295)
	     autonomous system number

  --bgp-mode <auto | external | internal>   (default=auto)
	     Whether to use eBGP or iBGP. Auto mode chooses depending on
	     BGP controller or falls back to iBGP.

  --bgp-multipath-as-path-relax <boolean>
	     Consider different AS paths of equal length for multipath
	     computation.

  --controller [a-zA-Z][a-zA-Z0-9_-]*[a-zA-Z0-9]
	     The SDN controller object identifier.

  --ebgp     <boolean>
	     Enable eBGP (remote-as external).

  --ebgp-multihop <integer>
	     Set maximum amount of hops for eBGP peers.

  --fabric   <string>
	     SDN fabric to use as underlay for this EVPN controller.

  --isis-domain <string>
	     Name of the IS-IS domain.

  --isis-ifaces <string>
	     Comma-separated list of interfaces where IS-IS should be
	     active.

  --isis-net [a-fA-F0-9]{2}(\.[a-fA-F0-9]{4}){3,9}\.[a-fA-F0-9]{2}
	     Network Entity title for this node in the IS-IS network.

  --lock-token <string>
	     the token for unlocking the global SDN configuration

  --loopback <string>
	     Name of the loopback/dummy interface that provides the
	     Router-IP.

  --node     <string>
	     The cluster node name.

  --nodes    <string>
	     List of cluster node names.

  --peer-group-name <string>   (default=VTEP)
	     Name of the peer group for this EVPN controller

  --peers    <string>
	     peers address list.

  --route-map-in <string>
	     Route Map that should be applied for incoming routes

  --route-map-out <string>
	     Route Map that should be applied for outgoing routes

  --type     <bgp | evpn | faucet | isis>
	     Plugin type.
