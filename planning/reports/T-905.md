# T-905 — Design system & accessibility pass

## What I built

Layered a WCAG 2.1 AA / design-system pass on top of T-901's already-merged
a11y bridge (consumed, not reimplemented — `TopologyA11yLayer.tsx` and the
roving-focus/label vocabulary in `a11yBridge.ts` were used as-is).

### 1. Density modes across the component library
New shared seam `web/src/components/density.ts`: a `Density` type
(`compact`/`comfortable`), a `DensityProvider` (ambient), and a `useDensity`
hook (explicit prop wins over ambient, defaults to `comfortable` = each
component's original spacing, so the whole change is additive — no existing
call site's output changes). Wired a `density` prop into all eight components,
each documented in its own doc comment (no new doc tooling, per the card):
`Button`, `Dialog`, `Drawer`, `EmptyState`, `ErrorBoundary`, `Table`, `Toast`,
`Tooltip`. `Table` and `Toast` re-provide the resolved density to their
subtree so nested `TableHead`/`TableCell`/toast cards inherit without prop
drilling. `ErrorBoundary` also gained a built-in default fallback panel (it
previously rendered `null`).

### 2. Dark-theme completion driving the v2 canvas
The v2 canvas already read `useThemeStore`/the `theme` prop for its draw
colors (T-901). Completed the coverage by fixing the dark-theme contrast
failures axe surfaced (see AC6) in the Switch faceplate, the top-bar search
placeholder, the segmented view toggle, and the primary Button — so both Graph
(canvas) and Switch views are AA-clean in dark mode.

### 3. Keyboard nav + visible focus ring
Every interactive map entity is reachable via Tab/arrow roving focus through
T-901's bridge; added a visible `focus-visible` ring to `EntityNode` (Graph
v1) and every `SwitchFaceplate`/`SwitchView` button (chassis, uplink, NIC,
access port, VLAN, VNet). Enter/Space activate exactly what a click does
(unchanged — reuses the existing `useRovingFocus`/`onActivate` path).

### 4. Screen-reader labels for every entity + badge
`a11yBridge.ts` gained an exported `badgeAriaParts(badges)` (the mgmt/
corosync/mgmt-path trio spelled out in words, drift called out as state, other
badges listed verbatim) — factored out of `entityAriaLabel` so DOM entities
that aren't shaped like the canvas `EntityNodeData` can produce identically
worded text. `EntityNode` (v1) and the Switch faceplate expose this via a
visually-hidden `aria-describedby` span, deliberately keeping their existing
plain-text `aria-label`s as the accessible *name* (several sibling
Vitest/Playwright specs locate these by exact name — `getByLabelText("eno9a")`,
`getByLabel("vmbr0 switch")`, `getByRole("button", { name: "vmbr0", exact:
true })`) while adding the richer kind/status/badge detail through the standard
accessible-description channel. The v2 canvas proxies keep using
`entityAriaLabel` as their name (T-901, unchanged).

### 5. Reduced motion
New `web/src/lib/useReducedMotion.ts` (`useReducedMotion` hook +
`prefersReducedMotion` one-shot + a named `motionConfig` budget). Wired so
`prefers-reduced-motion: reduce`:
- collapses the map's programmatic `fitView` pan/zoom easing to an instant
  jump (`TopologyPage.tsx`);
- disables the drift "pulse" — `EntityNode`'s `animate-pulse`, the Switch
  faceplate's, the v2 canvas's own imperative pulse (`canvasDraw.ts`'s new pure
  `pulseAlphaForPhase` + a `pulseAlpha` param, driven by a low-freq interval in
  `TopologyCanvasV2.tsx` that never starts under reduced motion or with no
  drift entity present), and the awaiting-confirm countdown dot
  (`CountdownBanner.tsx`) — each falling back to its static equivalent;
- drops dialog/toast/button transition animations.

### 6. Automated axe in the e2e suite
Added `@axe-core/playwright` (dev-only) and `web/e2e/a11y.spec.ts`: axe across
Dashboard, Topology (Switch + Graph v1 + Graph v2), SDN, Firewall, IPAM, the
changeset drawer, and Settings, asserting zero serious/critical violations,
plus a keyboard-only (no mouse/pointer input) traversal that reaches and
Enter-activates a v2 canvas map entity through T-901's bridge.

   whose disabled-control dimming is legitimately contrast-exempt).
