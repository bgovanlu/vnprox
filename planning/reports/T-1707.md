## 3. The API-freeze / compat decisions (summary for the reviewer)

- **Frozen at v3.0 (public compatibility contracts, §13):** the MCP nine-tool manifest (v1), the five
  plugin SDK interfaces (`plugin.APIVersion == "v1"`), and the WebSocket `"events"` stream schema
  (flat envelope + event set). Deprecation policy = the changeset API's: additive-only within a
  version; a breaking change mints a new version and keeps the old ≥1 minor release.
- **Peer wire protocol: NOT public, stays at version 2 (D11).** `ha/replicate` is additive at
  protocol 2 — it is an internal same-build-to-same-build contract, 503-nil-safe on non-HA peers,
  and only ever targets the configured standby, so it forces no version skew. This resolves the open
  note T-1704's report left for this freeze pass.
